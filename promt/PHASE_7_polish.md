## ♿ ШАГ 7.2 — ДОСТУПНОСТЬ И КАЧЕСТВО

### Семантика и aria
- Все формы — `<form>` с `<label>` (или `aria-label`)
- Кнопки-иконки имеют `aria-label`
- Модалки: `role="dialog"`, `aria-modal="true"`, focus trap, Escape закрывает
- Изображения товаров: `alt` = название товара (не пустой)
- Заголовки: иерархия H1 → H2 → H3 без пропусков

### Клавиатурная навигация
- Tab проходит по всем интерактивным элементам в логичном порядке
- Видимый focus-ring на интерактивных (не убирать `outline` без замены)
- Enter/Space на кнопках работает
- Escape закрывает модалки и дроуеры

### Контраст
- Проверить читаемость `--text-muted` на `--bg` и `--surface`
- Если контраст < 4.5:1 для обычного текста — поднять яркость

### Loading states (везде)
- Скелетоны вместо спиннеров (требование из мастер-промта)
- Skeleton.jsx использовать на: каталог при загрузке, карточка товара, листы заказов и т.д.

### Empty states (везде)
- Иконка + понятный текст + CTA-кнопка
- Корзина пуста → «В каталог»
- Заказов нет → «В каталог»
- Избранное пусто → «В каталог»
- Нет результатов поиска → «Попробуйте другой запрос»

### Error states (везде)
- Все запросы оборачивать в try/catch
- Ошибки → Toast с понятным сообщением (не «Internal Server Error», а «Не удалось загрузить товар, попробуйте позже»)
- Сетевая ошибка отдельно: «Проверьте интернет-соединение»

Frontend: Next.js 14, React 18, Tailwind, Zustand, TanStack Query

cd backend
cp .env.example .env  # заполнить
npm install
npm run dev           # http://localhost:5000

### 3. Frontend
cd frontend
cp .env.local.example .env.local
npm install
npm run dev           # http://localhost:3000

Админ: admin@stroyhub.local / admin12345
Пользователь: user@stroyhub.local / user12345

## Структура
/frontend     — Next.js
/backend      — Express + MySQL
/backend/uploads — локальные фото товаров
