# Как пользоваться этим набором файлов

Этот набор разрезает большой промт `MASTER.md` на 8 фаз для пошаговой работы с Claude Code.

## Файлы

```
MASTER.md                        — твой исходный полный промт (1002 строки), справочник
PHASE_0_foundation.md            — фундамент: структура, Express+Next пустые, дизайн-токены
PHASE_1_catalog.md               — каталог end-to-end (БД + API + фронт)
PHASE_2_auth.md                  — авторизация end-to-end
PHASE_3_cart_checkout.md         — корзина + оформление заказа
PHASE_4_account.md               — личный кабинет
PHASE_5_features.md              — 5 уникальных фич (калькулятор, мастер, bundle, комплектность, проекты)
PHASE_6_admin.md                 — админ-панель
PHASE_7_polish.md                — мобилка, доступность, безопасность, финальный аудит
```

## Workflow

### Подготовка
1. Создай новую папку проекта на компьютере (например, `/Users/you/stroyhub`)
2. Положи в неё все 9 файлов (MASTER + 8 PHASE)
3. Открой Claude Code в этой папке: `cd /Users/you/stroyhub && claude`

### Каждая фаза
1. **Новая сессия** Claude Code (или `/clear` если в той же)
2. Команда: `Прочитай файл PHASE_0_foundation.md и реализуй всё описанное в нём. MASTER.md — справочник для общего контекста, обращайся к нему если нужно. Не делай ничего вне рамок этой фазы.`
3. Дождись завершения
4. **Проверь критерии готовности** из конца файла фазы
5. Если что-то не так — попроси Claude Code исправить, не переходи к следующей фазе
6. Если ок — переход к Фазе 1: новая сессия, тот же промт с подменой номера

### Команды для каждой фазы (копируй)

```
Прочитай файл PHASE_0_foundation.md и реализуй всё описанное в нём.
MASTER.md — справочник для общего контекста, обращайся к нему если нужно.
Не делай ничего вне рамок Фазы 0.
В конце пройдись по списку «Критерии готовности» и убедись что все пункты выполнены.
```

Меняй номер: `PHASE_1_catalog.md`, `PHASE_2_auth.md`, и т.д.

### Между фазами

Запусти проект, потыкай в браузере, убедись что новая фича работает. Если нашёл баг — лучше сразу починить, до начала следующей фазы.

## Если что-то пошло не так

- **Claude Code сделал не то / сделал лишнее** → новая сессия с уточнённым промтом, опираясь на тот же файл фазы
- **Вылезла ошибка которую не понимаешь** → возвращайся ко мне в чат, покажи ошибку и контекст, разберёмся
- **Хочется поменять что-то в дизайне или логике** → правь сначала `MASTER.md`, потом соответствующий PHASE-файл, потом запускай Claude Code

## Важные напоминания

- Каждая фаза = новая сессия Claude Code. Иначе старый контекст забивает голову и мешает.
- Не пропускай проверки между фазами. Долг технический растёт быстро.
- MASTER.md держи неизменным как «эталонный источник». Если что-то меняется — отражай и в MASTER, и в фазе.
